## Publish checklist

1. Create a Medium draft; paste `medium-post.md` (convert headings as needed).
2. Upload each `assets/*.png` in place of the relative image links (Medium does not host relative paths).
3. Add a cover image (suggest `03-bolts10-board.png` or `06-live-anp.png`).
4. Publish → copy URL.
5. Post LinkedIn using `linkedin-post.md`; Medium URL in the **first comment**.
6. Do not publish the `_research-*.md` files.
